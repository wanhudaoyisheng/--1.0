怎么玩

  1. 展开一个人的信息条。点人物卡上的「展开信息条」，TA 说过的原话会逐字变成小方格。
  2. 点出可疑的字。在原话里挑出你觉得不对劲的词，按原文顺序会自动拼成一个关键词。
  3. 选一个目标，按解锁。把关键词指向某个人、或指向「世界观」——判定通过，就会翻出新的线索。
  4. 前置不足时会卡住。字猜对了但情报不够，向导会告诉你先去别处挖，不是你想错了。
  5. 撬开世界观。世界设定不足，故事推不动。看到像「设定」的词，试试指向世界观。
  6. 拼到终局。里程碑点亮的那一刻，故事会自己说完。

卡住了就点「提示」，提示分三级逐层递进，且不直接给答案。
